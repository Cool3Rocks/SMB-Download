# SMB Download

流程：配置 SMB → 浏览游戏文件夹 → 下载到本地 → 选择启动程序与名称 → 添加到 Steam。

## 本地构建

在项目根目录运行（Windows 上也可构建）：

```powershell
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run test:steam
node --test tests/test_smb_download_power.cjs
node --test tests/test_smb_download_delete.cjs
python -m unittest discover -s tests -v
pnpm run build
python tools/build_smb_download.py
```

输出 `artifacts/SMB-Download.zip`，ZIP 内只有 `SMB-Download/` 一个插件目录。
前端、Python 后端及 Linux SMB 依赖均已打包，不需要在 SteamOS 安装系统软件、挂载 SMB 或提供 sudo 给插件。
打包脚本默认按 Decky 官方构建使用的 CPython 3.11 / Linux x86_64 生成；其他运行时需在新构建目录中传入 `--python-version`。
参考：[Decky 官方构建配置](https://github.com/SteamDeckHomebrew/decky-loader/blob/main/.github/workflows/build.yml)。
第二次打包会沿用本地 `py_modules/smb_download_vendor`，无需重新联网。修改 Python 依赖时请使用新的构建目录。

源代码入口为 `main.py`、`src/index.tsx`。项目仅保留 SMB 下载、Steam 入库/删除、亮屏控制以及相关依赖和测试。
旧游戏库、模拟器、云盘、云存档、CRT、Rust 下载/解压内核及资源已删除。

## 部署与调试

1. 备份 Deck 上原插件文件夹和 `~/.local/share/SMB-Download`。
2. 查看 `/home/deck/homebrew/plugins`，使用 `SMB-Download` 作为插件目录；升级旧版本前先停用原插件，避免同时加载两份插件。
3. 将 ZIP 传到 Deck，在确认安装目录后将包内文件放到插件目录。也可使用当前 Decky 版本提供的开发者插件安装功能。
4. SSH 中执行 `sudo systemctl restart plugin_loader.service`，回到游戏模式，打开 Decky 的 SMB 下载入口。
5. 首先测试一个小文件夹，再测试真实游戏。

插件设置页支持查看日志。SSH 中可实时查看：

设置页提供“检查 SMB 依赖”，会显示后端实际 Python 版本、依赖目录、模块导入错误和完整 traceback。
SMB 包存在但 CFFI、cryptography 或动态库无法导入时，不再统一误报为“缺少 SMB 依赖”。

插件补充 CPython 3.11.7 的 `logging.config`、`socketserver` 和 `configparser` 源码及许可证。
Decky 的冻结 Python 运行时可能未收集这些模块，而 pyspnego 导入时需要 `logging.config`。
插件为已有 `logging` 包追加子模块搜索目录，并将标准库补充目录放在搜索路径末尾；已有标准库及日志处理器保持使用运行时原模块。

插件修复 `smbprotocol 1.15.0` 的目录生成器不支持 `with` 导致的浏览 `TypeError`。
改为遍历生成器并保证关闭，目录读取失败时也会释放 SMB 句柄。

```bash
tail -n 200 -f /home/deck/.local/share/SMB-Download/plugin.log
sudo journalctl -u plugin_loader.service -n 200 -f
```

## 使用

- 设置 SMB IP/主机名、端口、共享名称、用户名和密码。
- 游戏源目录是**共享内相对路径**，例如共享 `Games` 中的 `PC/Ready`；留空表示共享根目录。
- 本地安装目录可手动填写或通过文件选择器选择，可放在内置存储或 SD 卡。
- 保存并测试连接，点击文件夹行右侧的“下载”直接开始下载，或进入文件夹后点击“下载当前文件夹”。启动后自动进入任务页，显示创建、扫描与下载状态。支持中文名称和多层文件夹。
- 浏览时也可将当前 SMB 文件夹选为新的游戏源目录，再保存。
- 下载完成后在任务中打开入库设置，浏览本地文件选择真正的启动程序。插件不会自动猜选第一个 EXE。
- 下载时默认用文件夹名称作为游戏名称，可在入库设置中修改。
- 工作目录和启动程序均以游戏目录内相对路径保存，启动参数单独设置。Windows EXE 默认使用 Proton Experimental；也可取消或更换内部名称。
- 入库通过运行中的 Steam 客户端 `AddShortcut` / `SpecifyCompatTool` 等接口完成，不直接改写 `shortcuts.vdf`。通过 SteamGridDB 手动配图。
- 写入 Steam 的启动程序完整路径和工作目录自动加双引号，支持带空格的目录。已完成任务可点击“修正 Steam 启动设置”，更新原条目，不重新下载或创建条目。

## 状态与限制

- 首版同一时间运行一个下载任务；关闭页面不影响下载。
- 下载完成后的入库设置和“修正 Steam 启动设置”均在对应游戏任务下方展开，每次只展开一个游戏；关闭或完成入库后收起。
- 入库的“添加到 Steam / 关闭入库设置”、下载任务的“暂停或继续 / 取消”、设置页的“目录选择 / 保存 / 测试连接”和“日志 / 依赖检查”、SMB 浏览的刷新与目录操作均使用紧凑横排按钮，保留 Decky 手柄左右导航；窄窗口空间不足时换行。快捷访问面板只有一个入口按钮。
- “浏览 SMB”支持名称升序/降序、修改日期最新/最早优先排序，文件夹始终排在文件前面。搜索按当前目录的文件夹名称进行部分匹配，不区分英文大小写，不递归扫描 SMB；输入后点击“搜索”才筛选，“取消”清空输入并恢复全部条目。刷新保留已提交的关键词，进入另一个目录时清空关键词。
- 启动程序选择把游戏目录及全部子文件夹中的 `.exe`（不区分大小写）平铺列出，每行右侧点击“选择”，自动填入相对路径并启用 Proton；同名文件显示相对路径以便区分。不显示本地文件夹浏览、工作目录或启动参数输入项；工作目录自动使用 EXE 所在目录。新任务不附加启动参数，修正已有条目时保留任务原有参数。
- 默认开启“下载时保持亮屏”，可在设置页关闭并保存。扫描与传输期间临时禁用电池/接电两种模式的自动变暗和休眠计时，传输完成、暂停、取消或失败后恢复读取到的原值，等待手动入库不继续保持亮屏。结束后按原来的自动计时息屏，不强制立即关屏，也不拦截手动按电源键。
- 亮屏控制在插件全局运行，关闭 SMB 页面不影响；更改前写入本地 `smb-download-power.json` 恢复记录，正常卸载时恢复，Steam/Decky 重启后再次加载插件时恢复未完成的记录。Steam 电源接口或原值读取失败会在设置页和任务页显示错误，下载仍继续。读取失败时先在 Steam 电源设置中明确设置电池/接电的自动变暗与休眠计时，再重试；不会猜测原值或编辑 Steam 配置文件。
- 暂停、网络失败或插件重启后，需要点击“继续下载”。已写入的临时文件支持按字节续传。
- 未完成的任务可点击“取消下载并清除临时文件”。传输停止、文件句柄关闭后仅删除该任务的临时目录；其他任务、SMB 文件和已安装的游戏不受影响。取消后可重新下载同一文件夹。清理失败时提供重试按钮；取消过程中重启插件会继续清理。
- 已下载、已入库或入库未完成的任务可点击“删除游戏”。确认窗口列出游戏名、本地路径和删除范围：移除任务关联的 Steam 非 Steam 快捷方式、删除该任务的本地游戏目录及任务记录，SMB 源文件不受影响。先验证目标仍为任务创建的受管目录，再通过 Steam RemoveShortcut 移除条目并确认其消失，最后清理文件；缺少 Steam 验证接口或移除失败时保留文件。删除过程持久化 Steam 移除进度，文件清理失败或插件重启后提供重试；被改成符号链接或不符合原目录的路径拒绝删除。其他存储位置的 Proton 前缀、存档及 SteamGridDB 图片不在文件清理范围内。
- 任务固定记录创建时的 SMB 连接与目标目录，之后修改设置不会改变该任务。
- 目录名附加稳定的来源标识，避免同名游戏冲突。下载完成才将临时目录移动为最终目录，已有目标目录不会被覆盖。
- 续传前重新检查远端文件清单、大小和修改时间；文件发生变化时停止续传。需要重新下载变更后的版本时，首版可配置另一个本地安装目录创建任务。
- 同一来源和安装目录不重复创建任务；入库重试保存并复用 Steam AppID。若用户手动删除了该 Steam 条目，首版需要另建任务或手动重新添加。
- 配置密码保存在本地权限为 `0600` 的文件中，并非加密；不会通过页面读取接口返回。下载任务快照同样包含本地凭证，完成入库后清除任务快照中的密码。
- 暂不支持匿名 SMB、SMB 符号链接/目录联接、压缩包安装和安装器执行。原生 Linux 游戏可能需要自行补充其他程序的执行权限。
- 本地测试使用模拟文件源和 Steam 接口，真实 SMB、Steam UI、Proton 与手柄交互需要 Steam Deck 实机验收。

## 实机验收

验证连接失败提示、中文路径、空文件夹、暂停与断网后续传、插件重启、安装目录改动不影响任务、空间不足、启动程序选择、入库失败重试、添加后无需重启即在 Steam 游戏库“非 Steam”中显示、Steam 重启后条目保持，以及通过 SteamGridDB 设置封面。

入库通过 Steam 原生 AddShortcut 创建条目，只在 appStore 确认条目注册完成后写入名称、带双引号的可执行路径与工作目录、启动参数和 Proton。Steam 返回 ID 不等于游戏库已经完成同步；最多等待 5 秒，超时保留 ID 和任务，下次重试复用条目。缺少游戏库或启动设置接口时不报告成功。启动参数优先使用 SetAppLaunchOptions，兼容旧版本 SetShortcutLaunchOptions。

亮屏实机验收：先记录电池和接电的四个电源计时；开始大文件夹下载后离开插件页面，等待超过原定息屏时间；分别验证完成、暂停、取消、失败和插件重载后计时恢复，关闭亮屏开关后下载按原设置息屏。还需在当前 Steam 稳定/测试版验证接口兼容性。本地测试只验证编码与生命周期，不能代替 Steam Deck 屏幕实测。

插件显示名为 SMB Download，默认打开“浏览 SMB”。ZIP 内使用 `SMB-Download/` 插件目录，本地状态存放在 `~/.local/share/SMB-Download/`，Steam AppID 恢复键以 `smb-download-appid:` 开头。此次统一命名改变了旧版本的状态路径、状态文件名和恢复键，不会自动读取旧版本配置或任务；升级前请完成或取消旧任务，确认电源计时已恢复，并备份旧插件与状态目录。新版本需要重新配置 SMB。备选 EXE 每行使用虚线外框，行间距为 3 像素。
